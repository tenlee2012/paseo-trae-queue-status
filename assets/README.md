# Interface preview

`queue-status-preview.png` renders the current `QueueStatusCard` component from
`client/queue-status.tsx` with the light and dark theme palettes used by the component tests.
It shows the queued and generating states with sample messages from the queue-status tests.

The component tree was produced with React Test Renderer and its styles were exported through
Satori and resvg. The surrounding labels identify the sample states. This is a component preview,
not a screenshot of a running Paseo application, and it contains no account or conversation data.

The Hourglass and Info icons are from Lucide. Their license is in `LUCIDE-LICENSE.txt`.
